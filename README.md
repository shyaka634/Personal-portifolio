## 📖 About the Project

This is my **personal portfolio website** — a static web app built from scratch using HTML and CSS, with no frameworks or libraries. It serves as a central place to present who I am, what I build, and the projects I have worked on, including a Calculator app and a Todo App.

---

## ✨ Features

- 🦸 **Hero Section** — A welcoming intro with name, title, and call-to-action
- 🗂️ **Projects Showcase** — Highlights of personal and academic projects
- 💡 **Skills Section** — Overview of technical skills and tools
- 📊 **Dashboard View** — A secondary page with an extended overview
- 📱 **Responsive Design** — Adapts to different screen sizes using CSS
- 🎨 **Custom Styling** — Fully hand-crafted styles with no CSS frameworks

## 🚀 Getting Started

No installation or setup needed — this is a static website.

1. **Clone the repository**
   ```bash
   git clone https://github.com/shyaka634/Personal-portifolio.git
   cd Personal-portifolio
   ```

2. **Open in your browser**

   Simply open `index.html` in any web browser:
   ```bash
   # On Mac
   open index.html

   # On Windows
   start index.html

   # Or just double-click index.html in your file explorer
   ```

3. **Live Preview (optional)**

   If you have VS Code, use the **Live Server** extension for hot-reload during development.
